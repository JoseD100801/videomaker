# Carpeta de trabajo del Creador de videos

Las reglas del sistema viven en el plugin videomaker (skill `creador-de-videos`), así se actualizan solas con `/plugin marketplace update videomaker`.

- Antes de cualquier video o reel, carga la skill `creador-de-videos` y sigue sus fases. Empieza preguntando qué vamos a hacer.
- Proyectos nuevos: copia `proyectos/_plantilla` con el nombre del video (o usa `/videomaker:nuevo-proyecto`).
- Reels de referencia propios: `catalogo-videos/` (solo estudio, nunca se publican).
- Si falta alguna skill, corre `/videomaker:preparar`.

Escribe debajo las reglas que sean solo de este equipo.
